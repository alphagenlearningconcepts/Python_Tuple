Core Concept

What is a Tuple?

A Tuple is a collection of data like a list, but it is Immutable—you can never delete or make a change!

Immutable Data Structure

Immutable means unchangeable. Once a tuple is created in Python, its elements are locked in memory forever!

Syntax: Parentheses ()

Tuples use Parentheses () instead of square brackets [].

# Creating an Animals Tuple
animals = ("Lion", "Tiger", "Bear", "Elephant")

What is an Index? 📍

An Index is the numerical position of each item in the collection starting from 0!

Index 0
"Lion"
Index 1
"Tiger"
Index 2
"Bear"
Index 3
"Elephant"
print(animals[1]) # Output: Tiger

Tuple Packing & Unpacking

Pack values into 1 tuple, then unpack them into individual variables in a single step!

What is Tuple Packing?

Packing is putting multiple values into a single tuple variable.
my_tuple = ("Alice", "Bob", "Charlie", "Diana", "Ethan")

What is Tuple Unpacking?

Unpacking extracts tuple elements directly into separate variables!
a, b, c, d, e = my_tuple

Modifying Data

How do we add elements? Concatenation ➕

Tuples are immutable (no .append()), but we can combine tuples using the + operator to create a NEW tuple!

# Define two separate tuple variables:
tuple_1 = ("Apple", "Banana", "Cherry")
tuple_2 = ("Date", "Elderberry")

# Concatenate tuples into a new variable:
combined_tuple = tuple_1 + tuple_2
print(combined_tuple)
